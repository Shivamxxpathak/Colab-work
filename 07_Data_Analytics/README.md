# SuperStore Data Analytics

A portfolio-ready retail analytics project built with Python.

## What this project analyzes

- Sales and profit performance
- Category and sub-category profitability
- Regional performance
- Discount impact on profit margins
- Returned orders
- Product-level performance
- Monthly and yearly trends
- Executive KPIs and business recommendations

## Workflow

**Raw Excel data → Data cleaning → Feature engineering → EDA → Profitability → Discount analysis → Returns → Time series → Product analysis → Recommendations**

## Tools

Python, Pandas, NumPy, Matplotlib, Seaborn, Excel and Jupyter/Google Colab.

## Dataset

The notebook expects the existing `Datasets/SuperStore.xls` file in this repository, or `SuperStore.xls` uploaded beside the notebook in Google Colab.

## Notebook

[Open SuperStore_Data_Analytics.ipynb](./SuperStore_Data_Analytics.ipynb)

## Portfolio Summary

Analyzed SuperStore retail transactions to identify sales and profitability drivers across products, categories, regions, discounts, returns and time. Built executive KPI reporting and translated analytical findings into recommendations for pricing, discount control, product strategy and regional performance.
