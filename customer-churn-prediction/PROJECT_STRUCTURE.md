# Project Structure

- `src/churn_pipeline.py` — data loading, preprocessing, model training and evaluation.
- `src/visualize.py` — model comparison chart.
- `scripts/train.py` — command-line training entry point.
- `app.py` — Streamlit prediction interface.
- `data/` — dataset instructions; raw CSV is ignored by Git.
- `outputs/` — generated metrics, charts and trained model; generated artifacts are ignored by Git.
